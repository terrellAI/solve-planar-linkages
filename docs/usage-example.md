# 使用示例：从本次机构图到正向求解

![本次机构图](mechanism-input.png)

本页演示如何调用技能，不把未确认的连接关系写成事实，也不把示意图比例当作实际尺寸。

## 1. 读图与拓扑确认

先上传上图，再发送 README 中的入门提示词。
技能应首先给出带引线的标注图，并围绕以下事项询问。

| 图上信息 | 首轮需要确认的内容 |
|---|---|
| O、C 附近的固定支承符号 | 是否均为机架上的固定转动副 |
| A、B 及其连接线 | 独立连杆还是多铰点刚体；各铰点实际连接哪些构件 |
| B 与 C、D 附近的杆线 | B 是材料铰点、套筒中心还是别的约束点；是否存在共用刚体 |
| D、E 及右侧竖直导向 | 输出构件、连接杆、滑块和导轨分别属于哪个刚体；实际 P 副的位置 |
| A₁/A₂、B₁/B₂、D₁/D₂、E₁/E₂ | 是否表示同一机构的其他姿态，而非额外构件 |
| 左下方圆弧及右侧上下箭头 | 输入是否为绕 O 的旋转；输出是否为沿竖直导向的往复运动 |

这些问题是读图核实清单，不是已确认拓扑。
同一张图中线段共线、相交、成三角形，均不能单独证明它们是同一刚体。
若用户明确指出某点是导杆上的滑块中心，其滑移坐标应随运动变化，不能固定该点到导杆的距离。

用户可按实际结构逐条回复：

```text
固定点：……
运动刚体：L1包含……；L2包含……；……
R副：……与……在……连接。
P副：滑块……沿……滑动；导轨属于……。
输入：……；初始方向与转向：……。
输出：……。
带下标的点表示：……。
允许调整的尺寸：……；不可改变的尺寸：……。
```

## 2. 确认后给出计算目标

```text
以上拓扑确认无误，请继续。
无尺寸部分采用示例尺寸，并列出尺寸表及选择理由。
保持已经确认的刚体、运动副、装配分支与输入转向。
优先给出可分解为几何构造的正向求解顺序，不采用数值方程求解冒充正向构造。
验证全周期可达性和有限导轨接合；证明与0.1度采样结果分别说明。
动画使用真实逐帧求解：每圈300帧，每帧20ms，循环接缝检查通过，文件小于5MB。
另输出每10度坐标CSV、模型JSON、验证JSON及可复现脚本。
遇到奇异位形或不支持的闭环，报告原因和失败角度，不跳帧、不换根、不改拓扑。
```

## 3. 正向构造的方法

实际计算顺序依赖已确认拓扑。以下只是原语说明，不是本图已经完成的解。

1. 驱动旋转：以固定点为原点，用旋转矩阵生成输入铰点。
2. 两圆交点：根据已知点与杆长求交，保留初始装配的有向分支。
3. 刚体点变换：仅对已确认同属一个刚体的材料点使用共同位姿。
4. 圆与导轨交点：根据杆长和实际 P 副导向求输出点。
5. 整体检查：重算所有杆长、R 副共点、P 副共线、有限接合及周期闭合。

设两圆圆心为 P=(0,0)、Q=(6,0)，半径均为5，选择上侧分支，则中间投影距离为3、高度为4，交点为(3,4)。
这是两圆构造的独立手算例，不能当作本图的实际点坐标。
完整公式见 [几何推导](../references/geometry.md)。

## 4. 应收到的交付物

| 交付物 | 检查内容 |
|---|---|
| 拓扑标注图 | 编号、刚体归属、R/P 连接、输入输出与原图一致 |
| 尺寸表与推导 | 尺寸来源清楚，正向依赖顺序可解释 |
| 模型 JSON | 仅使用已支持原语；与确认拓扑一致 |
| 动画 GIF | 默认300帧、20ms、连续转向、无重复终帧、循环接缝通过 |
| 每10°坐标 CSV | 使用同一套点编号，不拿36帧采样直接制作动画 |
| 验证 JSON | 失败角度、杆长与运动副残差、分支、导轨接合、闭合与动画体积 |
| 复现脚本 | 不依赖私人账号、密码或临时绝对路径 |

本页未宣称本次机构已求解。上传后仍需确认实际拓扑，再生成该机构的模型与动画。
