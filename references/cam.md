# 尖顶直动盘形凸轮：统一行程函数与反转构造

## 输入与范围

先确认：尖顶从动件、固定直线导轨、凸轮转向、基圆半径 r0、导轨的有符号偏距 e、行程函数。新图仍先交付拓扑确认图，标出凸轮机架转动副、从动件机架移动副、尖顶接触及导轨方向；已有确认直接沿用。无尺寸时明确使用示例尺寸。

采用 x 向右、y 向上、凸轮中心 O=(0,0)、初始导轨 x=e。右偏为正，左偏为负；对心取 e=0。限定 r0>|e|，选取上方初始接触点。当前只支持理想尖顶直动从动件的规定接触运动，不证明力封闭、动力学、轮廓干涉或可加工性；滚子、平底和摆动从动件另行推导。

唯一行程接口为 `stroke(theta_deg) -> s`，自变量属于闭区间 [0,360]，单位为度；s 与 r0、e 使用同一长度单位。函数可封装解析式、分段式或离散数据插值，几何层不需要知道推程/休止/回程区段。要求有限非负值，参考零位 `stroke(0)=stroke(360)=0`；若原函数零位不在基圆接触处，先明确重新选择起始角。不要在函数内先取模，掩盖360度端点不闭合。周期延拓仅在端点验收通过后用于多圈调用。

## 推导与离散法

以 θ≥0 表示沿指定转向积累的输入角，R 为现有 `linkage.rotation` 的逆时针旋转矩阵，使用弧度。顺时针实际角为 −θ，反转角 β=+θ；逆时针实际角为 +θ，反转角 β=−θ。

- 初始轴向距离：l0=√(r0²−e²)。
- 实际尖顶：P=(e,l0+s(θ))。
- 凸轮固连坐标中的轮廓点：Q=R(β)P。
- 反转导杆切点：T=R(β)(e,0)；轴向 d=R(β)(0,1)。
- 零行程基圆交点：C=T+l0·d；Q=C+s(θ)·d。

反转导杆为 T+λd，满足 |T|=|e|、T·d=0，因此始终与偏心圆相切。**沿反转导杆量取行程**；一般偏置时 |Q|=√[e²+(l0+s)²]，不能把半径直接写成 r0+s。e=0 时偏心圆退化为中心，导杆过中心，无需除以 e。恢复实际转动：R(−β)Q=P。

以 θ_i 在 [0,360] 采样，逐点求 Q_i，再按角序连接成离散轮廓。默认0.1度生成轮廓和验收；折线只是轮廓的离散近似。检查端点、反转还原、导杆共线、偏心圆相切、零行程基圆半径及轴向行程残差。采样通过不代表任意自定义函数连续、轮廓无干涉或解析轮廓已证明；尖点或分段边界应额外求左右极限，必要时细分。不得仅检查动画的300个角度。

## 执行入口与复用

`cam.py` 提供 `Cam(stroke, base_radius, offset=0, direction='clockwise')`、`pose(theta_deg)` 和 `verify_cam(cam, step=.1)`。它复用 `linkage.rotation` 和 `GeometryError`，作为规定接触的独立适配器；固定R/P JSON求解器保持原有约束含义。

`run_cam.py` 复用 `run_model.save_gif_under_limit`，使用同一行程函数生成实际运动、反转作图、动态行程图，并导出每10度坐标、0.1度轮廓及验证结果。仅执行可信的 Python 行程文件；不要执行来路不明的上传代码，应先审查并自行写成明确函数。

从技能目录运行已提供的示例（尺寸均为教学示例）：

```bash
python scripts/run_cam.py references/examples/cam/stroke.py \
  --radius 40 --offset -10 --direction clockwise --out OUTPUT --gif
```

对心使用 `--offset 0`；右偏使用正偏距；逆时针使用 `--direction counterclockwise`。其它行程只需替换定义 `stroke(theta_deg)` 的文件。离散输入可在该函数中用 `numpy.interp` 返回标量；先检查角度严格递增、包含0和360、值有限、端点为零，注明采用线性插值及数据来源。

动画每帧重新构造，采用300帧、20ms、50fps、无重复360度帧，检查刚体材料点的有向角增量及循环接缝。实际导杆固定，凸轮按指定方向转动；反转视图凸轮固定，导杆连同偏置一起转动，尖顶逐步描线。行程图的游标、投影和数值均取该帧同一函数值。反转描线每圈清空属于作图状态，不是机构运动跳变。**两视图的凸轮基圆均用虚线**；偏心圆用不同色实线，对心时省略退化圆；凸轮轮廓用清晰实线。不要用固定的动画相位替代函数计算。
